To enter pipes through an in-side door.

## Examples

- A file dropped into a watched folder arrives.
- Each attachment of a collected email arrives as its own file.

## Rationale

Arrive, in-flight, and depart name a file's passage through pipes in order. "Receive" and "intake" lost to the warehouse's word.
